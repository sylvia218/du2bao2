# Install the footer and legal pages

1. Download and unzip this package.
2. Upload every file inside the folder to the root of your existing GitHub repository.
3. Replace files with the same names.
4. Keep your real Supabase values in `config.js`. This package preserves the uploaded `config.js`.
5. Commit the changes and wait for GitHub Pages to redeploy.
6. Hard-refresh the website. The service-worker cache was changed to `du2bao2-v4-legal-footer`.
7. Test the footer on:
   - `index.html`
   - a `product.html?id=...` page
   - mobile view
8. Open every legal page and replace all text inside square brackets before public launch.

## Important scope note

This package upgrades the footer and adds the information pages requested. It does not change the Supabase schema or seller listing form. The legal pages are drafted around the current Stage 1 model where buyers and sellers arrange payment, shipping and returns directly.
